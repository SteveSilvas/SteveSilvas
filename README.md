<summary><strong>🛠️ Detalhes técnicos deste repositório (portfólio)</strong></summary>

Este repositório é o meu portfólio pessoal, construído com
[Next.js](https://nextjs.org) (App Router), React, TypeScript e Tailwind CSS.

### Requisitos

- Node.js `>= 20.9.0` (recomendado: Node 20 ou 24 LTS)
- npm

### Como rodar

```bash
npm install        # instalar dependências
npm run dev        # desenvolvimento em http://localhost:3000
npm run build      # build de produção
npm start          # executar o build
npm run lint       # análise de código com ESLint
```

### Estrutura

```
src/
├── app/                  # rotas (App Router)
│   ├── layout.tsx        # layout raiz (Navbar + Footer)
│   ├── page.tsx          # home
│   └── screens/          # About, Projects, Training, Certifications,
│                         # Experiences, Habilities, Contact
├── Components/           # componentes reutilizáveis (Navbar, Footer, ...)
└── assets/               # imagens, projetos e certificados
```
